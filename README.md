# 剧有词

一个从影视台词中学习英语的静态网站。每个剧集或精选片段都是独立的学习单元，可以结合英文原句、中文释义和回忆练习积累真实表达。

## 功能

- 浏览、搜索和筛选不同剧集
- 每集独立的重点词语、音标、例句与中文翻译
- 学习新词、回忆词义和英文填空练习
- 浏览器原句朗读
- 选中句中单词或短语查看中文释义
- 将自选词加入词汇总览并进行搜索
- 使用浏览器本地存储保存学习进度和自选词
- 导入、导出及重置单集学习进度

## 本地运行

网站不需要构建步骤。克隆仓库后，在项目根目录启动任意静态文件服务器：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

直接打开 `index.html` 也可以浏览大部分内容。划词释义需要网络连接。

## 项目结构

```text
.
├── index.html          # 剧集书架
├── assets/             # 全站样式与交互脚本
└── episodes/           # 各个独立学习页面
```

本项目不托管电视剧或影视视频。页面中的观看按钮仅链接到第三方公开页面；相关视频、封面和剧名的权利归各自权利人所有。学习词条与中文释义用于语言学习和交流，请在使用、修改或分发时遵守相应平台条款及所在地法律。
